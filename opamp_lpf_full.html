Active Low Pass Filter using an Op-Amp

Learning objectives: (1) explain how an RC network filters; (2) derive H(jω), fc and roll-off; (3) design for a given gain and cutoff; (4) solve GATE-style problems; (5) answer interview questions on active filters.

1. Introduction and objectives

Definition. A low pass filter (LPF) passes signals below a cutoff frequency fc and attenuates those above it. An active LPF combines an R-C network with an op-amp, so it can also provide gain and drive a load.

Principle. Capacitor reactance XC = 1/(2πfC) falls as frequency rises. In the inverting LPF the capacitor is in parallel with Rf, so at high frequency the feedback impedance drops and the gain drops with it.

Why it matters. LPFs give anti-aliasing before ADCs, noise reduction on sensor signals, DAC output smoothing and baseband selection in receivers. A passive RC filter changes with load and cannot amplify; the op-amp removes both limits.

Prerequisites

Ideal op-amp and virtual short, inverting amplifier, capacitor impedance 1/(jωC), transfer function, decibels, Bode plot, passive RC filter.

Terminology

TermMeaning
Passband / stopbandFrequencies passed (0 to fc) / strongly attenuated (well above fc).
Cutoff fcFrequency where gain is 0.707 of the passband gain (−3 dB).
Roll-offAttenuation slope beyond fc: −20 dB/decade per order.

A0Passband (DC) gain.
τ = RfCfTime constant; fc = 1/(2πτ).
GBW, SROp-amp gain-bandwidth product and slew rate (LM741: about 1 MHz, 0.5 V/µs).

Classification

  • By element type: passive (RC) or active (op-amp).
  • By configuration: inverting or non-inverting.
  • By order: first, second (Sallen-Key, MFB), higher.
  • By response: Butterworth (flat), Chebyshev (ripple, sharper), Bessel (linear phase).

3. Working principle

  1. The input current Vin/R1 flows into the virtual-ground node (zero current enters the op-amp).
  2. That current must pass through Zf = Rf || 1/(jωCf), so Vo = −VinZf/R1.
  3. At low frequency Cf is open, Zf ≈ Rf and gain = −Rf/R1.
  4. At high frequency Cf shorts Rf, |Zf| falls as 1/f and gain falls at −20 dB/decade.

Assumptions

Ideal op-amp with GBW much larger than fc × gain, linear region (no clipping), no load effect.

Advantages

  • Gain and cutoff set independently
  • Load-independent output
  • No inductors needed

Limitations

  • Needs power supply
  • Bandwidth limited by GBW and slew rate
  • First order gives only −20 dB/decade
  • Inverting type inverts phase by 180°
Common misconceptions. (a) "Any op-amp with a sine in and a different wave out is a filter": an open-loop op-amp is a comparator and outputs a saturated square wave (about ±13 V); it has no frequency-selective element. (b) "fc is where gain is zero": it is where gain falls 3 dB. (c) "Higher C raises fc": it lowers it.

5. Equations and derivations

5.1 Transfer function

Zf = Rf/(1 + jωRfCf)  ⇒  H(jω) = Vo/Vin = −Zf/R1 = −(Rf/R1) / (1 + jω/ωc)
ωc = 1/(RfCf),  fc = 1/(2πRfCf)

5.2 Magnitude and phase

|H| = (Rf/R1)/√(1 + (f/fc)²),   φ = 180° − tan−1(f/fc)
Gain (dB) = 20 log10(Rf/R1) − 10 log10(1 + (f/fc)²)

At f = fc: |H| = A0/√2, gain −3.01 dB from passband, extra lag 45°. For f >> fc: slope −20 dB/decade.

5.3 Non-inverting LPF

A0 = 1 + Rf/R1,  fc = 1/(2πRC),  H = A0/(1 + jωRC)

5.3b Second order (Sallen-Key, equal R, C)

fc = 1/(2πRC), roll-off −40 dB/decade; Butterworth when A0 = 1.586 (Q = 0.707)

5.4 Step response and limits

vo(t) = Vfinal(1 − e−t/τ), τ = RfCf; tr (10–90%) = 2.2τ = 0.35/fc
Slew-limited frequency: fmax = SR/(2πVp)

6. Solved numerical problems

Problem 1 (Easy): design. Design an inverting LPF with gain −5 and fc = 2 kHz using Rf = 10 kΩ.
R1 = Rf/5 = 2 kΩ. Cf = 1/(2π × 10 kΩ × 2 kHz) = 7.96 nF (use 8.2 nF standard; fc becomes 1.94 kHz).
Problem 2 (Moderate): gain and phase. R1 = Rf = 10 kΩ, Cf = 10 nF, f = 5 kHz.
fc = 1.592 kHz; f/fc = 3.14; |H| = 1/√(1 + 9.87) = 0.303 = −10.4 dB; lag = tan−1(3.14) = 72.3° beyond the 180° inversion (net phase 180° − 72.3° = 107.7°).
Problem 3 (GATE-style): output amplitude. Rf = 100 kΩ, R1 = 10 kΩ, Cf = 1.59 nF, input 0.1 V peak at 10 kHz.
fc = 1/(2π × 100 k × 1.59 n) ≈ 1 kHz; A0 = 10; |H| = 10/√(1 + 100) = 0.995; Vo,peak = 99.5 mV (the passband gain of 20 dB has fallen to about 0 dB).
Shortcut: well above fc, |H| ≈ A0fc/f = 10 × 1 k/10 k = 1.

8. Core-company interview preparation

Why use an active LPF instead of a passive RC?

It does not change with load (low output impedance), can provide gain and buffers the source.

How do you pick R and C for a target fc?

Choose R from 1 kΩ to 100 kΩ (noise and loading), compute C = 1/(2πRfc), then use standard values and check tolerance (E24 resistors, 5% or better capacitors such as C0G/film).

Why does a first-order filter give −20 dB/decade?

Beyond fc |H| ∝ 1/f. A 10× rise in f gives 1/10 the gain, which is −20 dB.

What limits the filter at high frequency?

Op-amp GBW and slew rate; the closed-loop gain at high frequency also rises toward the noise gain, and parasitics create a stopband floor.

When would you pick Butterworth over Chebyshev or Bessel?

Butterworth for the flattest passband; Chebyshev for a sharper transition with passband ripple; Bessel for linear phase and minimal pulse overshoot.

Output of an open-loop op-amp looks like a square wave. What is it?

A comparator. No feedback means huge gain, so the output saturates at the rails with a sign set by V+ − V−.

Industry perspective. Engineers choose the filter order and type from the required stopband attenuation, simulate in SPICE (Multisim, LTspice), then verify on the bench with a network analyzer or function generator plus scope, checking component tolerance and op-amp noise.

High-priority GATE points

  • fc gives −3 dB and 45° for the RC term
  • 10× fc gives about −20 dB below passband
  • Inverting adds 180°; gain magnitude Rf/R1
  • Order n gives −20n dB/decade

Common errors and troubleshooting

  • Output clipped: input times gain exceeds rails; reduce gain.
  • Wrong fc: used R1 instead of Rf in the inverting formula.
  • No filtering: C open or wrong position.

Memory aid: "Low pass: cap in feedback, high frequencies shorted away." Interview must-knows: fc formula, roll-off, active vs passive, comparator vs filter.
